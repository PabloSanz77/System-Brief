# UniPay

UniPay es un sistema web para la gestión de pagos de colegiatura universitaria.

Permite a los estudiantes:
- Registrarse e iniciar sesión
- Consultar saldo pendiente
- Registrar pagos mensuales
- Ver historial de pagos

El objetivo es centralizar la gestión financiera básica de estudiantes en un sistema digital simple.# System-Brief
